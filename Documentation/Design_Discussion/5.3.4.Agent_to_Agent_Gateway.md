# 5.3.4 Agent-to-Agent (A2A) Gateway

## Problem

Interview asks: *How would AI Gateway support agent-calls-agent? What about identity, delegation chains, recursion guards? Where in the code?*

Today the lab is **one agent → one LLM**. CrewAI/LangGraph can chain agents — the gateway needs to know **who** is calling, **who delegated**, and **stop loops**.

**Read first:**

```text
server.go L125                    internalReqID — links listener + upstream ext_proc
backendauth/credential_override.go   per-request credentials (extend for delegation)
mcpproxy/authorization.go         CEL rules on tools/backends
filterapi/filterconfig.go           Backend config (add a2a_agent type)
Documentation/5.Policy_Controls.md  Section 4 — credential injection story
```

---

## Answer

**AI Gateway** — identity, delegation, scoped keys, and hop limits need request context and backend config; Envoy only routes traffic.

Envoy: optional **header-only** max-hop reject at router (cheap guard). **AI Gateway**: validate signed delegation chain (`server.go`), read/append agent ID (`processor_impl.go`), issue scoped tokens (`backendauth`), route to `a2a_agent` backend. **MCP agent calls**: same rules in **mcpproxy** CEL.

---

## How

```text
Agent A ──► Agent B ──► (maybe) LLM / Agent C
        │
        ▼
┌──────────────────────────── Envoy :8080 (proxy) ────────────────────────────┐
│  ★ optional ★  router: reject if hop-count header > max (no body parse)    │
│  ✗ not here    signed chain verify · scoped token · a2a_agent backend pick  │
│                ext_proc gRPC → upstream ext_proc → TLS to agent URL / OpenAI │
└──────────────────────────────┬──────────────────────────────────────────────┘
                               │ gRPC
                               ▼
┌──────────────────────── AI Gateway :1063 ─ ext_proc ─────────────────────────┐
│  server.go L128            ★ validate delegation chain · maxHops · cycles ★  │
│  processor_impl.go L213    ★ read x-agent-id · append to chain header ★     │
│  backendauth               ★ CredentialOverride → scoped token per hop ★    │
│  filterapi                 Backend.type = a2a_agent + agent endpoint URL     │
│  server.go L125            internalReqID links listener + upstream streams   │
└─────────────────────────────────────────────────────────────────────────────┘

MCP agent-to-agent (parallel path):
┌──────────────────────── AI Gateway :8081 — mcpproxy ───────────────────────┐
│  authorization.go CEL   ★ agent_id · hop_count · delegation scope ★        │
└─────────────────────────────────────────────────────────────────────────────┘
```
