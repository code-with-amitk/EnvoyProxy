# 5.3.1 Data Loss Prevention (DLP)

## Problem

Interview asks: *Where would you add DLP? Which libraries? How for streaming prompts?*

Agents can send **private data** (emails, API keys, internal IDs) to OpenAI — sometimes pulled in by MCP tools (files, SQLite, web fetch). The gateway is the last place you can stop that leak.

**Read first:**

```text
processor_impl.go L213          ProcessRequestBody — where prompt JSON is parsed
processor_impl.go L495          ProcessResponseBody — where LLM reply is handled
endpointspec/endpointspec.go    how chat messages are parsed today
redaction/redaction.go          today: redact for logs only (extend to enforce)
Documentation/5.Policy_Controls.md   Phase 5 Lua block (simple pattern, not full DLP)
```

---

## Answer

**AI Gateway** — not Envoy. DLP needs **parsed chat JSON** (message fields, tool args) and **LLM response text**; that happens in `processor_impl.go` after `ParseBody`, not in the proxy.

Envoy only forwards the body via ext_proc gRPC. Optional: a **coarse Lua regex** on raw body in Envoy for obvious secrets (fast pre-filter) — but real DLP (Presidio, field redaction, output scan) lives in **AI Gateway**.

On match: log, redact (`[REDACTED]`), or block (403). Fail closed in prod. Streaming: buffer chunks → scan at end-of-stream.

---

## How

```text
Agent prompt (+ MCP tool text in JSON body)
        │
        ▼
┌──────────────────────────── Envoy :8080 (proxy) ────────────────────────────┐
│  Lua (optional coarse regex only)  →  rate limit  →  ext_proc gRPC  →  …   │
│  ✗ not full DLP — raw body only, no ParseBody, no response scan            │
└──────────────────────────────┬──────────────────────────────────────────────┘
                               │ gRPC (headers + body)
                               ▼
┌──────────────────────── AI Gateway :1063 ──────────────────────────────────┐
│  Stream 1 routerProcessor                                                    │
│    ProcessRequestBody L213  →  ParseBody  →  ★ DLP INPUT scan ★             │
│         │ log / redact / block                                               │
│         ▼                                                                    │
│  Stream 2 upstreamProcessor  →  inject key  →  Envoy  →  OpenAI            │
│                                                                               │
│  (response path) upstreamProcessor ProcessResponseBody L495                  │
│         →  ★ DLP OUTPUT scan ★  →  log / redact / block  →  back to agent   │
└──────────────────────────────────────────────────────────────────────────────┘
```
