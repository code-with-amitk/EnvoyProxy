# 5.3.2 Content Safety

## Problem

Interview asks: *How to screen harmful input/output at the gateway without slow UX? Local (LlamaGuard) vs cloud (Azure)? Streaming when tokens arrive before the check finishes?*

Your lab blocks one jailbreak phrase in **Envoy Lua** — easy to bypass by rephrasing. You need smarter checks on **prompt and response text**.

**Read first:**

```text
config/envoy.yaml                 Lua jailbreak block (Tier 0 — already works)
processor_impl.go L213            input: full prompt after ParseBody
processor_impl.go L495            output: LLM response chunks / EndOfStream
Documentation/5.Policy_Controls.md  Section 5 — content policy you demoed
```

---

## Answer

**Split by tier.** Tier 0 (known jailbreak **strings**) → **Envoy Lua** on raw body — fast, already in your lab. Tier 1 (LlamaGuard) and Tier 2 (Azure), plus **all output scanning**, → **AI Gateway** — needs parsed prompt text and streaming response chunks.

Check input after `ParseBody` (L213); check output per chunk in `ProcessResponseBody` (L495) and **abort early** on bad content. Config tiers in `filterapi`.

---

## How

```text
        │
        ▼

│  ★ Tier 0 ★  Lua on raw body — known jailbreak phrases → 403               │
│  ✗ not here  semantic classify · LlamaGuard · Azure · output scan           │
│              rate limit → ext_proc gRPC → router → upstream ext_proc        │
└──────────────────────────────┬──────────────────────────────────────────────┘
                               │ gRPC
                               ▼
┌──────────────────────── AI Gateway :1063 ────────────────────────────────────┐
│  Stream 1 routerProcessor  ProcessRequestBody L213                           │
│    ★ Tier 1 ★  LlamaGuard classify INPUT (after ParseBody)                 │
│    ★ Tier 2 ★  Azure classify INPUT (optional, high-risk routes)            │
│         ▼                                                                    │
│  Stream 2 → Envoy → OpenAI                                                 │
│                                                                               │
│  (response) ProcessResponseBody L495                                         │
│    ★ Tier 1/2 ★  classify OUTPUT per SSE chunk · abort early on severe hit  │
│         → block / truncate / annotate → back to agent                      │
└─────────────────────────────────────────────────────────────────────────────┘
```
