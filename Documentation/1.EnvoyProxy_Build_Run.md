# Envoy proxy?
- This is L7/L4 edge/service reverse proxy written in C++
- It is a engine responsible for accepting client connections, enforcing routing, and moving bytes.

## Clone, Build, Run

### Clone
```bash
sudo apt-get update
sudo apt-get install -y git python3 cmake curl build-essential clang

# Download Bazelisk binary
sudo curl -L https://github.com -o /usr/local/bin/bazel
sudo chmod +x /usr/local/bin/bazel

git clone https://github.com/envoyproxy/envoy.git
```

### Build
```bash
cd envoy
bazel build -c opt //source/exe:envoy-static --jobs=2
```

### Configuration
```yaml
$ config/envoy.yaml
  admin:
    address: 127.0.0.1:9901

  clusters:
  -name: openai_cluster
    endpoint: api.openai.com:443 
```

### Run
```bash
$ scripts/envoy.sh start
Expected cgroup v2 file not accessible at /sys/fs/cgroup/    << Ignore on WSL, Since WSL doesn’t mount the path

http://127.0.0.1:9901/ready -> Live

$ scripts/envoy.sh status  # hits /ready
$ scripts/envoy.sh stop
```

## Hit openai /v1/models endpoint
- envoy.yaml(127.0.0.1:8080) has openai_listener which goes to api.openai.com.
- Request Flow
```bash
curl  →  Envoy (127.0.0.1:8080)  →  HTTPS  →  api.openai.com:443
         /v1/models                           /v1/models
         Authorization: Bearer ...            Authorization: Bearer ...  (passed through)
```
