# Environment and Planning — Phase 0

This document records Phase 0 decisions for the Envoy AI Gateway interview assignment. 

## 0.1 Lab Machine

| Requirement | Assignment minimum | This machine | Meets? |
|-------------|-------------------|--------------|--------|
| OS | Ubuntu 22.04 LTS recommended | Ubuntu 22.04.5 LTS (jammy) | Yes |
| vCPU | ≥ 4 | 12 (6 cores × 2 threads, Intel i5-1335U) | Yes |
| RAM | ≥ 8 GB | 7.5 GiB visible in WSL2 (~8 GB allocated; host has 16 GB) | Yes |
| Runtime | Single machine, no multi-VM | WSL2 on single host | Yes |


## 0.2 Agent Framework Choice

### Selected framework: **Agno** (formerly Phidata)

Repository: https://github.com/agno-agi/agno

### Why Agno (and not the alternatives)
- Agno is lightweight, minimal dependencies; faster install
- Clean JSON tool calls, easy to correlate with Envoy access logs
- Excellent MCP support
- Support OpenAI-compatible API — supports `base_url` override so all LLM traffic can point at Envoy

| Framework | Why not chosen for this lab |
|-----------|----------------------------|
| **OpenHands** | Full coding agent with browser/shell/file tools — excellent traffic volume, but heavier setup and harder to isolate LLM vs tool traffic in a timed interview. |
| **LangGraph** | Strong graph-based reasoning and large ecosystem, but more boilerplate for a focused gateway demo. |
| **CrewAI** | Best for multi-agent model-routing demos, but adds orchestration complexity beyond what we need for first end-to-end run. |
| **AutoGen** | Good for multi-turn conversation patterns; less ideal for crisp, log-readable tool call structures. |


## 0.3 MCP Server Selection

Assignment requires **≥ 2 MCP servers**, with preference for no paid API keys. At least one **stdio** and one **HTTP** (routed through Envoy) is recommended.

### Selected servers

| # | Server | Transport | Role in lab | Via Envoy? |
|---|--------|-----------|-------------|------------|
| 1 | `@modelcontextprotocol/server-filesystem` | **stdio** | Read/write report files in a sandboxed directory | No — direct subprocess |
| 2 | `@modelcontextprotocol/server-sqlite` | **stdio** | Store structured index/metadata in local SQLite DB | No — direct subprocess |
| 3 | `mcp-server-fetch` | **HTTP** | Fetch web pages for research step | **Yes** — agent URL points at Envoy |
